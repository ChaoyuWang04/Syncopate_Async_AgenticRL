```
Track A · 异步 Agentic RL 后训练系统：正确性、吞吐与算法-系统联合优化   2026.08–至今

背景: 多轮工具调用 agent 的 RL 后训练，轨迹长短天然不齐（同批最慢/平均 1.37–2.75×）；
     4×消费级 GPU、无 NVLink/P2P（卡间带宽≈数据中心互联 1/35）。通用 RL 框架
     （verl/FSDP/vLLM 栈）的权重同步、批组织、采样调度假设在该负载与拓扑上逐条静默失效。
     全程与 Code Agent 协作开发，以判据纪律 + 实验报告体系（E00–E29）保证每个结论可复验。

○ 定位并修复三个"机制在但不报错"的框架级正确性缺陷（均深入框架底层机制，上游 issue/PR
  已提交〔编号〕）：
  ① PyTorch FSDP 退化网格静默降级，梯度归约落在单成员组——3 个 rank 各训各的（跨 rank
    相对差恒 √2）；修复后逐位一致，归约口径实证 3卡=1卡（1.000000）。
  ② verl 训推分离路径每次同步搬运 8.4GB 冻结基座而 LoRA 增量从未下发，生成策略停在起点
    两个月、全程指标正常；自研 adapter 推送补丁：载荷 8414→252MiB（33×）、同步 6.25→0.97s、
    占步 0.8%，并以数值判据验证"推对了"（两侧 logprob 差回落至引擎噪声地板 3.4e-4）。
  ③ 打包前向绕过根 FSDP 导致梯度归约竞态（静默不同步）；以 30 秒级脱 Ray 最小复现定案
    （此前 16 轮整跑调试无果），修复后与健康路径逐位相同。
○ 训练吞吐与 IO：识别 agentic 负载 87% 训练 token 为组内重复题面，激活上游 PrefixGrouper
  死代码并补齐掩码/因果对齐等 6 处接线——端到端 2.31×（fp32 逐位等价）；实测 KL 惩罚项仅占
  损失 0.011% 且对任务分无影响（MDE 内），砍掉 ref 前向再省 15.4%；按 requires_grad 筛选
  CPU 快照 52×（端到端 5.7%）；定位框架对 LoRA 训练按全量 state_dict 落盘（每次 27GB、
  97% 为与基座逐字节相同的冻结权重），改 LoRA-only 存档后同尺子单次 save 7.9→0.83s（9.5×）、
  ckpt 12× 更小、单跑写盘 108→~9GB，断点续跑合成加载与 adapter 链路全验（E29）。
  生产步速 11.33 → 〔Z〕s/step，整机占空比 31% → 〔W〕%。
○ 用数学工具定界优化算法：序列级重要性采样在 694-token 轨迹上指数崩塌（χ²_seq/χ²_token
  =989×）；bf16 合并损失的 ULP 分析（RL 增量 1.3e-5 < bf16 刻度 9.1e-5 ⇒ 合并毁掉 adapter
  作用的 50%）——两项分别决定了 IS 聚合口径与权重同步方案的取舍。
○ 端到端闭环与可观测性：四条常驻判据 + 任务级冻结评测配对回归（自报 MDE）作为一切优化的
  精度闸；首条干净 RL 曲线（任务分 0.356→0.902，候选配对 +0.186, t≈16）；以 cap 单调恶化
  显影 reward 盲区反哺算法侧。
○ 异步体制的边界测量：装齐下发/完成/中止三事件记账，实测短思维链负载处于陈旧度消融的
  零剂量区（partial_ratio 恒 0）——给出该体制的成立边界；CoT 负载支持落地后 rollout 显著
  变慢，首次进入非零剂量区，测得陈旧度代价曲线〔CoT 落地后〕（原论文列为 future work 的测量）。

Track B · GPU 通信/低精度/算子：以硬件物理上限为唯一基准的优化          2026.08–至今

○ 集合通信性能悬崖根因定位：从"3 卡分片慢 6 倍"逐层排除（带宽/次数/拓扑/协议选择），定位到
  NCCL Simple kernel 的 16 字节向量化对齐悬崖——固定一切只挪 4 字节：13.2→1.1 GB/s（12×）；
  真实 ZeRO-3 路径 99.9% 的 all_gather 字节错位（每 rank 恰差 4 字节，broadcast 0% 构成天然
  对照）；应急协议切换 3.33×，根治方案（分片补齐 16B 对齐）已提上游〔编号〕。

  先量分母（该层仅占前向 4.28%）后主动降级不写融合 kernel，如实给出"上限 4.3%、切片即得
  4.0%"的否定结论。
○ 软硬结合·消费级 Blackwell（sm_120）新特性兑现：实测热点 GEMM 全部仍是 Ampere 代 kernel
  （cutlass_80）——新硬件的原生低精度没人去拿；FP8 点亮后真实形状 1.70–2.22×，并以数值定界
  划出不可用域（FP8 误差=训推一致性地板的 316×，rollout 侧禁用）；为 FP8 吞吐找到训练侧
  新消费者（〔update_actor/old_log_prob，队列「FP8 新消费者」〕前向，端到端〔 〕×，任务配对回归〔 〕）；
```
