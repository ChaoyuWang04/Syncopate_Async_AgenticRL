## 0 · ★★★ 第一条规矩：框架是**变量**，不是目录结构

我们大概率会换训练后端（FSDP → FSDP2 / Megatron / torchtitan），
甚至可能换整个训练框架（verl → slime / 自己写）。**所以这个目录的组织方式必须能活过换框架。**

⇒ **实验按「问什么问题」编号，不按「用什么框架」编号。**

```
✅ E02 · 数据并行的分片策略        ← 问题不变，framework 换了照样是这个问题
❌ E02 · verl FSDP 实验            ← 换个框架这份报告就死了
```

**框架/后端/版本一律记在每份报告的「环境指纹」里，当作受控变量。**
同一个问题在两个框架上测过 ⇒ **写进同一份报告的两行**，这样才比得出来
（而且「换框架前后同一个数差多少」本身就是有价值的结果）。

## 1.5 · ★ 两条 track：编号是身份，track 是视图（2026-08-14 新增）

目标从「把 4×5090 压榨到极限」收窄成**两个有真实需求支撑的项目**，
于是需要一层「这个实验服务哪条线」的索引。**但 E 编号不重排**——
§1 的规矩仍然有效（别的文档引用「E02 的结论」，编号一动引用就烂）。

```
docs/infra_exp/TRACK-A-hardware-kernel.md   负载形状 × 硬件拓扑 决定该写什么算子
docs/infra_exp/TRACK-B-framework-async.md   agentic RL 训练系统的框架级改造
docs/infra_exp/NARRATIVE-AND-RESUME.md   🆕 「怎么讲」：完成态的故事线 + 简历（未测的留〔 〕）
```

★ **第四份是 2026-08-16 新增的，它和前三份的分工是**：
E 报告答「量到了什么」、track 答「这条线要兑现什么、现在在哪」、README 是索引，
而 **NARRATIVE 答「这些实验最后要变成什么」**——★ 它**只写完成态**：
叙事与简历都按「所有实验做完」来写，还没测的数字留 `〔 〕`。
**不维护「现在能写的」那一版**——进度归 track 文档，两份并存最后会两份都不准。
⇒ 由它反推出的实验优先级判据是：**能不能把某个 before 变成 after**
（见 `00-INFRA-HANDOFF.md` §5）。

⇒ **track 文档回答「这条线要兑现什么、现在在哪」，E 报告回答「我们量到了什么」，
本文件是索引。三者不重复内容。**

★ **判据（这次改组的核心纪律）**：每个实验都要能回答
**「它服务哪条 track 的哪条兑现物」**。答不上来的**不是先做后想，是先停放**——
见下表 ⚪ 无主 的三个。理由本身是资产（§1「作废不删」的同一条精神）。

## 4 · 三条纪律（从主线继承，代价已经付过）

1. **先写预测再跑。** 见模板 §1。
2. **每个加速比都要有同分母。** 固定 trace 重放、同一批 case、同样的组结构，
   优化前后各跑三遍取中位。**不用合成负载。**
3. **任何 infra 改动都要过任务级尺子。** 冻结 EVAL × 8 采样配对比较（自报 MDE）
   + cap 构成 + 决策位熵。**只报吞吐不报任务精度的优化不算完成。**

★ 第四条，这个目录特有的：
4. **报告只增不改。** 结论变了就加「修订」小节写清楚哪天为什么变，
   **不要把旧数字直接覆盖掉** —— 那样就永远查不出「我们是什么时候开始信错的」。

★★ 第五条（2026-08-16 新增，代价刚付过）：
5. **观察到一个问题 ≠ 有人在解决它。**
   每份报告 §8「下一步」的**每一条**，要么对上 TRACK-A/B 队列里的一个编号，
   要么**显式写「已结案 / 已停放 / 挂主线 + 理由」**。
   ⇒ 核对表在 `TRACK-B §3.6` 和 `TRACK-A §7.6`，**每次收工过一遍**。

   > **起因**：占空比 31% 被当成「产出」讲了两天，但它其实只是测量 + 归因——
   > 列出来的三个成因里，**只有一个有实验对着**，另外两个（陈旧度节流、资源配比）
   > 是空白，其中一个甚至**从没被列进成因表**。
   > 同一次核对还翻出：`partial_rollout` 从没触发（只写在 E08 里，队列上没有）、
   > 训练侧三次前向占 72%（只被侧面蹭到）、满载降频（自己写着「会污染所有对照」却没进队列）。
   >
   > ⇒ **教训：归因做完会有一种「已经解决了」的错觉。
   > 防它的办法不是更努力地记得，是让空白在表格里显形。**
