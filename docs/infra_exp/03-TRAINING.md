# Infra · 训练、RL、async 与 OPD

> 本文是画像后的训练定位/回归参考，不是首次运行的全量前置。先按[TASKS](01-TASKS.md)跑真实负载；探索最低健康与优化验收按[实验协议](06-EXPERIMENTS.md)。

训练引擎范围固定为 **FSDP2 和 Megatron**。其他训练后端不进入当前实验；普通 Transformers/HF 只作为独立数学或机制参考，不冒充训练侧结果。

## 1. 负载与更新目标

固定一MoE一dense主模型，优先复用Volume；从受支持的真实框架入口、公开输入和短但足够观测的更新循环起步。全参/LoRA、SFT/RL/OPD 都是实验维度，不要求连续读取原业务 SFT→RL→OPD 产物。非零可控 adapter 可用于同步测试，但必须登记生成方式、目标参数、SHA 和适用范围；不能冒充学会任务的模型。

小型合成模型用于数学与接口，大模型用于真实 kernel、路由、并行和显存。随机路由的微测试不代表真实预训练 MoE 的专家负载。

## 2. 优化方案形成后的定向正确性参考

- 输入 token、位置、attention/loss mask、padding/packing 边界逐项核对。decode 后再 encode 不能代替原始 token。
- 更新目标按官方算法定义：token mean、sequence/prompt mean 是不同目标，不强行全改为 token mean。切 micro-batch 后与对应整批目标比较，尾窗口和不同 rank token 数都覆盖。
- 区分外层调用、内层 optimizer 完成、状态 step 前进、非零目标梯度和参数变化。AdamW 仅 weight decay 导致变化不是学习信号。
- 分布式通过正式 root forward/backward 路径，验证真实进程组、梯度与参数；FSDP 空 shard 合法，不要求本地变化张量数相同。
- 全参、LoRA、TP/EP 映射各自核对；保存加载后能接下一步。先正常恢复，主动故障注入另行登记与批准。
- 独立参考、正对照和故意错输入/权重的离线负例必须能发现错误；不把宽容阈值当正确性。

## 3. 有证据需要时再查训练与推理差异

先固定 base、相同 token/mask/位置/精度，无 LoRA；再按需要加入 adapter、batch 邻居、packing、GDN、MoE、引擎优化。保存逐 token 概率和逐层观测；同引擎重复、批次变化、跨引擎差分别报告。差异可能来自合法数值敏感性，也可能是错误；不能预设同 seed 输出必然一致或差异必然可接受。

对 MoE 记录 expert IDs、权重、重排和还原；对 GDN 记录实际 prefill/decode 路径和状态。相同载荷送达不等于实际计算用了它，接收和后续输出都要对账。

## 4. async 与摆放

colocate/separate表示角色位置，sync/async表示执行时间关系，分别设计变量。Q05/B12仅保留为方法参考；真实画像显示重叠机会后，优先在同一个受支持入口中比较同步与异步，固定角色资源、更新目标、数据与同步频率，不用main_ppo对比另一个入口来声称单因素。具体支持/源码/资源须实验预注册，不能从文档例子直接晋级。

同工作量且角色资源相同，理想同步约为生成时间R+训练时间L+同步时间S；异步重叠后受max(R,L)及暴露的同步/队列开销限制。额外生成、积压、同步暂停可能抵消收益，async不保证加速。

| 维度 | 必须量化的读数与口径 |
|---|---|
| 收益/成本 | 实际进入非零optimizer update的有效mask token数E /墙钟T、更新数U/T、E/GPU秒；独特消费token和跨epoch重复呈现分别记。有效计算不等于有效学习 |
| 时间 | 生成/评分/前后向/optimizer、队列等待、权重打包/传输/加载、暂停/drain、终态收尾；重叠区间单独记，不能相加冒充墙钟 |
| 浪费/积压 | 完整生成token G = 独特消费C + 丢弃D + 终态积压Q；中止部分token与重算另记；丢弃分过期/过滤/错误/收尾原因。PPO clip不是丢弃率；token占比不冒充GPU时间浪费 |
| 陈旧度 | 消费时optimizer步−产生权重对应步；同步版本差；token生成到消费的秒龄。三种单位分开，按token加权及按轨迹分别输出均值/P50/P90/P99/max、N与分位数算法；partial模式须分段版本 |
| 策略漂移 | 同token、同训练评分后端测δ=logπ当前−logπ产生时；数值残差ε=logπ产生时−rollout记录值另测。原始差=δ+ε，不能拿跨引擎误差直接称为陈旧损害 |
| 校正代价 | r=exp(δ)及ESS/N=(Σr)²/(NΣr²)先标为同训练后端的漂移诊断；实际重要性校正另用真实行为采样概率，登记温度/top-p/top-k与支持集。输出预注册边界下裁剪率与实际拒绝mask；token/序列权重分开。采样KL估计有方差，不能冒充完整分布KL |
| 更新影响 | 同一当前参数、同一保存数据/优势下，比实际陈旧目标与控制目标的梯度cos、相对差、范数比及更新差。仅说明目标/估计器敏感性；不同数据的新鲜梯度不能当真值；比较optimizer更新还须从相同optimizer/scaler/调度器状态分叉，保持裁剪和超参数一致。短探针不证明统计bias、长期收敛或业务损失 |

每项均输出两臂绝对值、差值/比值和重复波动，陈旧度按年龄分桶。先用真实FSDP2或Megatron入口验证更新、接收权重与版本使用，再量速度。阈值为0的同步臂需实测版本年龄；某个配置值不是年龄上限证明。诊断评分与梯度对照置于测速之外；固定轨迹回放和真实动态生成分别报告。不能为制造陈旧度静默加延迟或提高阈值。

### 重复前缀训练的条件触发参考

Q09/B13已暂缓，只有真实重复前缀计算占比触发时再调查FSDP2与Megatron：前者以训练状态分片为基础，后者覆盖TP/PP/CP/EP等模型并行；这是项目选定的互补覆盖，不是市场份额排序。查配置→模型包装→实际forward/backward调用链及当前上游替代，再量共享比例、命中、mask/位置/loss/梯度与时间/显存。上游配置、旧actor接线、本地历史patch、新engine真实命中分别记录。一个后端未支持，不强行套另一个后端的实现或退回FSDP1；不开启GDN/LoRA等未经支持认证的组合。推理KV cache不是训练前缀复用证据。

## 5. OPD 独立探针

先明确上游支持与待补缺口。教师和学生词表/输入格式要兼容，冻结教师只前向；KL 的方向、全词表/近似、text/think/tool mask 和全局分母逐项登记。学生生成的原始 token 必须直接进入教师/学生前向。

同模型零 KL、真实前后向零 mask、非零教师分布差和仅 weight decay 的负例分别验证。性能测试需有代表性的有效蒸馏 token；相同学生教师的零梯度只能证明零对照，不是更新性能。

摆放/批处理、分块 logits/KL、教师热切和学生同步各为独立问题。改变蒸馏目标的 text+think、top-k/采样近似单开实验，不冒充相同目标的系统加速。多教师技能融合任务属于独立 Sandbox Lab。
