# Infra · 项目表述与证据边界

项目以开源贡献为方向，研究真实训练与推理配置下的正确性、稳定性、速度、容量和通信问题。实验组负责背景调查、最小复现、定位、实验性修复、验证和记录；疑似上游问题移交 [upstream](../upstream/README.md)，正式 PR 调查、提交与评审跟进由独立负责人处理。

当前实验地图和各组任务只在 [Infra TASKS](../infra_exp/01-TASKS.md) 维护，不在本文复制待办。原业务数据构建、完整学习链与业务服务验收已停止，两个 Lab 默认独立。

已有证据仍有边界：B01 环境认证、B02 分段机械全链、B03 局部身份/更新及小模型恢复、B13 初始通信/GEMM 读数，均不能扩大为新的固定源码性能提升。各次运行的原始设置与结果以 `_audit/infra/Bxx/REPORT.md` 为准。

公开表述必须能追到具体报告、模型/源码/硬件和工作量；组件加速与端到端加速分开，短跑与长期稳定性分开。新 GPU、候选探针、未验配置和 DRAFT 均不写成已完成结果，issue/PR 状态由 upstream 核验后引用。
