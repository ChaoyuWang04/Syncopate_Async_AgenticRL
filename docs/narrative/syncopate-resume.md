## 2 · 项目 A：Agentic RL + OPD 基座模型后训练（完成态）

**背景**：面向广告投放优化师场景，训练可自主调用 30+ 业务工具、完成多轮闭环的
Agent 基座模型（Qwen3-4B，4×RTX 5090 全流程自建）。

**核心工作**：

- **环境与数据**：构建 Function Call 确定性沙箱（30 工具全实现）；脱敏组合 2500+ 条任务；
  筛选 SFT 冷启数据为 RL 制造可优化空间。v14 世代升级为**会话数据工程方法论**：
  「程序造事实·教师穿语言·判据把关」——事实骨架走沙箱真回放，语言表面由教师模型多版本
  生成，中间以五类建库门禁焊接（监督 token 口径的份额带宽 / 话术密度与病句闸 /
  OOV 教学面隔离 / 考场被判句零泄漏 / 语义冻结）；判别型行为数据强制**成对照对**
  （同历史前缀 → 概念追问 vs 数据追问分叉），根治单侧数据教反判别边界的实测问题。
- **外部语料融合（双模式，零直灌）**：模式 A 题库注入（WildChat-1M 中文子集 21 万段 +
  smoltalk-chinese 按质量分精筛，外部只出 user 侧文本，gold 全部自产）；模式 B 模式抽取
  （从真实对话挖省略追问句式聚类 42 模板、从 R1 蒸馏语料挖自我修正正则 14 条——
  外部文本零入库，只取分布形状）；license 分级审计（gated/GPL 弃用决策在案）。
- **奖励设计**：5 维加权子分 + 35 类分数硬封顶约束（cap），判分依据沙箱终态事实；
  cap 表与行为读数（该 defer/误 defer 双向拆分）常驻对照，多次抓获 reward
  hacking 指纹（false_claim 位移、话术复读 66% 占比等）。
- **GRPO 训练**：基于 verl 自研多轮工具调用采样循环；TIS 修正训推不一致；任务分池
  动态调度（EMA 方差加权 + 饱和降权 + 权重地板）防分布向短易任务漂移；早期按意图
  裁剪工具菜单（输入 token −59%、有效梯度密度 ×2.1），后按产品裁定演进为全量菜单
  模型自选。fully_async 3+1 拓扑 400 步零中断，行为守卫（defer 连零/截断/KL 地板/
  磁盘）带自动停机与集群清收。
- **OPD（on-policy distillation）**：教师=裸底座、逐 token 反向 KL、只蒸自然语言段
  （BPE offset 对齐分段器 + reply 值白名单防蒸工具段）；双教师路由（闲聊←底座 /
  任务←候选冻结锚）；训后说人话盲评超过教师本体。
- **CoT 冷启与按需思考契约**：难例选择器（评测卡死格→训练同族映射 + 前沿闸）+ 逐步
  rejection sampling（教师持全套工具 schema 与 gold 前缀独立解题，n=8 只收「教师自选
  动作=gold」的思考——思行一致构造性成立，不是给答案编理由）+ 中文/长度/段数闸；
  think-on 升为训练/评测/部署统一契约（探针实测推翻"空块比例"错误归因：think-off 模板
  在结构上剥夺思考位，两个方向都没有梯度）；按需思考双侧门槛（难例触发 ∧ 简单题抑制）；
  思考做轻（1–2 段关键推理）解开份额带宽与行数的数学冲突——**可达性预算先算后训**
  （钉死判据前先算"这个数在当前数据上可不可达"）。
- **评测科学（与数据同权重的工程面）**：冻结配对 EVAL（343 case，MDE 自打印）；
  考场单遍方差实测 29pp → **四遍聚合判定口径**；in-vocab/OOV held-out 双词表拆分
  「规则泛化 vs 记忆」；判据上线前**负向认证**（先证明会红才许守门）；机判首用必人核；
  说人话人工盲评闭卷带钥匙。
- **机理级归因与契约重构（v15）**：定位 RL 后行为退化的完整因果链——行为标签寄生于
  自研终答 JSON 壳（预训练零先验弱通道），训练分布外无锚 + GRPO 组内零方差不可逆
  ⇒「起点越好、无锚漂移越危险」；据此完成 v15 契约重构：行为迁入 function calling
  强通道（session.defer/clarify/reject/report 信令工具族——行为=显式动作，runtime 可
  编排挂起/等待/终止），终答纯自然语言；行为标签改由轨迹形态推导（不再要求模型自报），
  判分逻辑同构保持，以新旧两路逐 case 对拍（150/150 同分）与五类劣化负向认证收口。
- **训练-线上同形工程与测量系统重修**：通查出训练样例与生产请求 **7 处不同形**
  （多轮历史折叠文本 vs 真消息对 / 助手占位符 / 字段清单划重点 / 对象自选 / 时间格式 /
  工具菜单 / think 回灌）——全部对齐到线上侧，固化为「同形断言」测试族并进数据出厂
  体检（"两个东西应当相同"型判据 + 负向认证会红）；多轮数据升级为真实消息对〔W2〕。
  R5 复盘定性"六条不达标只有一条真读数、其余全是尺子的病"，据此立**门槛三查**
  （可测：n×MDE 分辨得出阈值 / 可达：当前数据先算一遍 / 阶段归属：该不该本阶段考）
  并重修考卷 v4——补 defer/clarify/难例考区与思考率尺子，判卷器五类劣化负向认证〔W1〕。

**成果**（两代分段，口径不混）：

- v13 世代（0→1 建线，正确系统世代 2048 冻结配对尺）：平均任务得分 **0.356 → 0.711
  （SFT）→ 0.897（RL-100 候选）/ 0.902（峰值）**；343 题逐题配对三计数 **298 变好 /
  43 没动 / 2 变差**（t=32.9，MDE 0.033，出处 `compare e27_base_off vs cand_v13r2_rl_s25`）；
  行为读数：该 defer 100%、误 defer 0%、REJ 0.97；cap 全线大降（false_claim 380→80 ·
  behavior_mismatch 330→1 · max_steps 227→0 · missing_*_check 93→3）。
  ⛔ 旧初稿的「8.1%→92.3% 通过率 / 证据缺失率 43%→5% / 18/21 超闭源旗舰」一族
  **全库无出处**（2026-09-01 查证，系动手前初稿遗留），已废弃不得再引。
- v14 世代（会话能力，2048 冻结配对尺）：任务分 0.711 → 0.799（SFT）→ 0.868（RL 峰值）；
  说人话盲评（满分 2）0.60 → 1.37（OPD，超教师底座 1.14）→ **1.46**；多轮指代续查
  36% → **92%**；概念解释词表外泛化 50% → 71%（iv/oov 双轨测量）；模板话术占比
  66% → **1%**。
- v15 世代（契约重构 + 同形重修，考卷 v4 口径）：行为语义正确率〔W5〕；多轮承接
  L1/L2〔W5〕；难例思考触发率〔W5〕；RL 后行为形态跌幅〔R6〕——对照组（v14 壳通道
  RL 后 defer 表达 100→0）的完整机理归因与修复方案在案，本代成败判据即按此设计。
- 方法论产出：数据五闸 / 四遍聚合 / iv-oov 拆分 / 负向认证等评测-数据协同规范全部
  文档化并在三个数据世代复用。

## 3 · 项目 B：Agent Serving 与生产级 Harness（完成态）

**背景**：将已训模型上线为可长期运行的生产级 agent 服务——执行状态活在数据库而不是
HTTP 连接里，幂等、崩溃可恢复、全程证据可溯源；同时作为模型行为的**真实反馈源**闭环
回流训练。设计总纲：**进程可以死，表不能丢**——每个机制都要答"哪个进程死掉之后，
怎么靠表活过来"。（服务性能/压测数字归 infra 版；本版写可靠性-正确性-产品-回流。）

**核心工作**：

- **Run 资源化与幂等入口**：执行建模为有生命周期的一等资源（六入口·六状态三活三终，
  没有 DELETE/PUT——run 是只能推进的历史）；请求级幂等两把锁（`unique(org,key)` +
  规范化 input_hash）三态语义（新建 201 / 命中 200 / 冲突 409），并发双击竞态由数据库
  约束兜底；resume 回队列保"同一时刻单执行者"不变量；双层错误码（HTTP 码给网关、
  稳定业务码给前端做自动决策）；多租户隔离进 SQL（org 只源于鉴权注入，前端不可伪造）。
- **两本账数据层与状态机**：状态（覆盖写）与事件（append-only、单调 sequence）分账；
  行级序号分配器保无洞无撞（行锁内取号，负向认证 MAX+1 必撞）；全部状态迁移收敛
  **唯一入口**（九边白名单 + 三终态出边空集 + 一事务写全状态/事件/审计，reason/actor
  必填——签名即制度）；协作式取消（取消是意图字段不进状态枚举，worker 在安全点兑现）；
  CI 级判据：全仓绕过状态机的裸赋值零命中。
- **可靠执行三道防线（at-least-once 语义下副作用恒一）**：Outbox 让消息不丢（三写同
  事务 + dispatcher 退避补投）；lease+心跳让执行权不争（条件 UPDATE 抢占、TTL=3×心跳、
  sweeper 只收"确过期"——慢不当死）；幂等五层让副作用不重（终态检查→claim→工具幂等键
  →重放复用→唯一约束）。写类工具**意图日志**两阶段落库（先记"我要做"再做）；崩在
  副作用与记录之间时标 `response_lost`——系统显式表达"我不知道"，禁止自动重试，由
  对账任务按幂等键向平台去重账本回查回填（回填+事件+审计同事务）；端到端故障注入
  三分支（崩溃恢复/重复投递/半成功）副作用计数恒 =1〔K8〕。
- **Tool Runtime 受控边界**：横切收口 ActionGate——模型只能"提出请求"，权限/幂等/
  审批/审计/成本/步数全部在唯一出口裁决；硬规则写进注册断言（有副作用⇒幂等键生成器
  + output_schema + timeout 必填，不满足注册不进来）——把"登记≠实现"这类静默缺口
  在结构上堵死；工具返回过 output_schema 防脏观测反灌 context（线上幻觉与训练数据
  污染双防）；失败结构化分诊（code/message/retryable 三读者），"防线生效不是故障"
  （权限拒绝记账不告警，守护告警信噪比）。
- **过程可视与人机协同**：SSE 按事实层/唤醒层/传输层三分（**先落库再推送**，通知只是
  唤醒不是事实）；断线 after/Last-Event-ID 双路补发，断线期间执行不停、重连零丢失；
  事件三层分级（public/internal/audit）payload 两视图——库里存全、推前端剥内部字段；
  `model.thinking` 思考流折叠可视化；高危操作 preview + 审批卡（审批人看到"退哪一单、
  为什么"而不是"模型想调工具"），审批意见注入续跑；**会话级多模型 dev mode**：
  三模型三卡并排、会话锁定模型、真人 A/B/C 对照实测。
- **生产硬化与变更可逆**：SLO 九条全部一键读数（没有对应 SLO 的层=正确性在线上不可
  验证）；run/org 双级预算（超限"还有救"转等待人工而非判死）；**兜底生效次数**
  （duplicate_prevented）列为一等公民指标——它量的是"离出事还有多远"；四种"事实上的
  schema"（checkpoint/事件/工具 args/job payload）带版本号 + 读侧版本网关（不认识的
  版本拒绝转人工，不崩不猜）；发布五能力（开关/停队列/禁工具/回滚/drain）全部实际
  演练过——"没演练过的回滚等于没有回滚"；灾备按异地仓库干净重建全链实测〔K11〕。
- **回流飞轮（与训练线的闭环）**：结果信号结构化落库（feedback/annotation 绑 run_id；
  症状与病因分列；同 run 多行 append，业务结果可推翻主观点赞——两把尺子有时间差）；
  归因强制含 `external_system_error`——"模型没错、是环境错"的样本零进负样本池，防
  训练信号符号反转；trace→评测 case 通道（expected 只能人工签字、原始 trace 哈希不变、
  source_run_id 可追回复查）；晋级三硬门禁（安全零容忍不取平均 → 通过率不低于线上 →
  人工 review），`/auto-apply` 类接口**永不实现**（最强的权限控制是能力不存在）；
  训练导出默认拒绝（准入 AND / 出局 OR）+ 导出留痕。**考场即生产栈**：三层考场直接
  跑在生产 runtime 上，评测分布=线上分布。

**成果**（已实测的报数；施工验收项以〔任务ID〕留位）：

- 真人在用的全链产品：会话→步骤流→审批→结论→追问，真浏览器全链实测；真人实测回流
  单日产出 **5 项判定书级发现**（标签漂移/空头支票/考卷盲区等），直接改写训练判定书。
- 正确性判据体系：幂等/越权/回放序/终态事件契约测试全绿；压测当场抓获并修复 3 个
  真 bug（SQL 类型/工具崩溃带走 run/事件序竞态）；RL adapter 热切换服务带合并保真
  断言（拦截 bf16 舍入损失）。
- 施工验收基线：故障注入三分支副作用恒一〔K8〕· 崩溃恢复时长〔K8〕· SLO 九条实测
  基线〔K11〕· 灾备重建 RTO〔K11〕· 发布五能力演练记录〔K11〕。
