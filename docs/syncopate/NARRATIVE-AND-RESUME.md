## 2 · 项目 A：Agentic RL + OPD 基座模型后训练（完成态）

**背景**：面向广告投放优化师场景，训练可自主调用 30+ 业务工具、完成多轮闭环的
Agent 基座模型（Qwen3-4B，4×RTX 5090 全流程自建）。

**核心工作**：

- **环境与数据**：构建 Function Call 确定性沙箱（30 工具全实现）；脱敏组合 2500+ 条任务；
  筛选 SFT 冷启数据为 RL 制造可优化空间。v14 世代升级为**会话数据工程方法论**：
  「程序造事实·教师穿语言·判据把关」——事实骨架走沙箱真回放，语言表面由教师模型多版本
  生成，中间以五类建库门禁焊接（监督 token 口径的份额带宽 / 话术密度与病句闸 /
  OOV 教学面隔离 / 考场被判句零泄漏 / 语义冻结）；判别型行为数据强制**成对照对**
  （同历史前缀 → 概念追问 vs 数据追问分叉），根治单侧数据教反判别边界的实测问题。
- **外部语料融合（双模式，零直灌）**：模式 A 题库注入（WildChat-1M 中文子集 21 万段 +
  smoltalk-chinese 按质量分精筛，外部只出 user 侧文本，gold 全部自产）；模式 B 模式抽取
  （从真实对话挖省略追问句式聚类 42 模板、从 R1 蒸馏语料挖自我修正正则 14 条——
  外部文本零入库，只取分布形状）；license 分级审计（gated/GPL 弃用决策在案）。
- **奖励设计**：5 维加权子分 + 35 类分数硬封顶约束（cap），判分依据沙箱终态事实；
  cap 表与行为读数（该 defer/误 defer 双向拆分）常驻对照，多次抓获 reward
  hacking 指纹（false_claim 位移、话术复读 66% 占比等）。
- **GRPO 训练**：基于 verl 自研多轮工具调用采样循环；TIS 修正训推不一致；任务分池
  动态调度（EMA 方差加权 + 饱和降权 + 权重地板）防分布向短易任务漂移；早期按意图
  裁剪工具菜单（输入 token −59%、有效梯度密度 ×2.1），后按产品裁定演进为全量菜单
  模型自选。fully_async 3+1 拓扑 400 步零中断，行为守卫（defer 连零/截断/KL 地板/
  磁盘）带自动停机与集群清收。
- **OPD（on-policy distillation）**：教师=裸底座、逐 token 反向 KL、只蒸自然语言段
  （BPE offset 对齐分段器 + reply 值白名单防蒸工具段）；双教师路由（闲聊←底座 /
  任务←候选冻结锚）；训后说人话盲评超过教师本体。
- **CoT 冷启**：难例选择器（评测卡死格→训练同族映射 + 前沿闸）+ 终答步 rejection
  sampling（n=8 取「教师自选动作=gold」的思考路径，思行一致构造性成立）+ 中文/长度闸。
- **评测科学（与数据同权重的工程面）**：冻结配对 EVAL（343 case，MDE 自打印）；
  考场单遍方差实测 29pp → **四遍聚合判定口径**；in-vocab/OOV held-out 双词表拆分
  「规则泛化 vs 记忆」；判据上线前**负向认证**（先证明会红才许守门）；机判首用必人核；
  说人话人工盲评闭卷带钥匙。
- **机理级归因与契约重构（v15，进行中）**：定位 RL 后行为退化的完整因果链——行为标签
  寄生于自研终答 JSON 壳（预训练零先验弱通道），训练分布外无锚 + GRPO 组内零方差
  不可逆 ⇒「起点越好、无锚漂移越危险」；据此发起 v15 契约重构：行为迁入 function
  calling 强通道（session.* 信令工具族）、终答纯自然语言，假说先行（双臂对照实验
  设计已就绪）〔R0-R6〕。

**成果**（两代分段，口径不混）：

- v13 世代（0→1 建线，终态判分口径）：端到端任务通过率 8.1% → 9.5%（SFT）→
  **92.3%**（GRPO），平均任务得分 0.52 → 0.95；证据缺失率 43%→5%、越权操作率
  28%→3%；18/21 意图主题超过闭源旗舰 zero-shot 基线。
- v14 世代（会话能力，2048 冻结配对尺）：任务分 0.711 → 0.799（SFT）→ 0.868（RL 峰值）；
  说人话盲评（满分 2）0.60 → 1.37（OPD，超教师底座 1.14）→ **1.46**；多轮指代续查
  36% → **92%**；概念解释词表外泛化 50% → 71%（iv/oov 双轨测量）；模板话术占比
  66% → **1%**。
- 方法论产出：数据五闸 / 四遍聚合 / iv-oov 拆分 / 负向认证等评测-数据协同规范全部
  文档化并在三个数据世代复用。

## 3 · 项目 B：Agent Serving 与产品壳（完成态）

**背景**：将已训模型上线为多渠道稳定服务与可实测的产品壳，幂等、崩溃断点可续、
全程证据可溯源；同时作为模型行为的**真实反馈源**回流训练判定。

**核心工作**：

- **可靠执行与故障自愈**：异步执行逐步落库；关键业务层幂等；崩溃断点续跑人工兜底；
  横切收口 ActionGate（权限/幂等/重试/成本闸/审批/审计/步数上限，模型不可触达）。
- **过程可视与人工审批**：SSE 事件流带 Last-Event-ID 断线补发；高风险操作自动转
  人工审批，审批意见注入后续执行；行为差异渲染（等待/澄清/拒绝各自卡片）。
- **推理过程可视化（CoT 流）**：`model.thinking` 事件链路（decider 提取 → 事件流 →
  前端折叠组件），思考按需展开不占版面；think 开关为部署侧契约分叉、显式登记。
- **多模型对照（dev mode）**：三模型（底座/SFT/RL）三卡并排服务，**会话级模型锁定**
  （创建即定、结构上不可改）+ 按会话路由 decider + 模型徽章；支撑真人 A/B/C 对照
  实测——实测产出五项模型行为发现直接改写训练判定书（标签漂移/空头支票/考卷盲区等）。
- **成本治理与数据回流**：模型与工具调用逐条计量；全链路回放排障；高危操作全量审计；
  线上轨迹人工审核脱敏后回流评测集。**考场即生产栈**：三层考场（单轮任务/多轮承接/
  说人话盲评）直接跑在生产 runtime 上，评测分布=线上分布。

**成果**：任务创建成功率 >99.9%、普通工单 P95 <60s、任务失败率 <1%、高危操作审计
覆盖率 100%；真人实测回流机制单日产出 5 项判定书级发现；RL 模型 adapter 形态
无缝热切换服务（合并保真断言拦截 bf16 舍入损失）。
