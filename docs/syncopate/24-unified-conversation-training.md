## 2 · 总设计：数据合一、监督分家

**一份 v14 多轮会话数据**，每条会话逐 token 标三类段，各走各的监督：

| token 段 | 监督 | 教师/信号 | 绝不允许 |
|---|---|---|---|
| 自然语言段（reply 值/闲聊/承接语） | OPD 逐 token 反向 KL | 裸底座 Qwen3-4B（think-off） | 教师碰工具段 |
| 工具调用段（tool+arguments JSON） | SFT CE（gold）+ RL reward | 沙盒逐轮可验证评分 | 用教师分布监督 |
| think 段（P2 起） | 蒸馏冷启（off-policy）+ RL | 大教师 think-on（Qwen3-8B/14B），**只留末答对的轨迹** | 无过滤直灌 |
| 任务段防漂移锚 | 候选冻结副本 KL 锚 | 自己 | —（J-7 原设计保留） |

**多轮难度爬梯**（每级可独立验收，机判规则见 P0）：

```
L1 闲聊承接        上文问定义、下文省略式追问（"ROAS呢?"）→ 续接解释而非查数据
L2 指代续查        "它/那个campaign 的转化呢" → 正确解析指代并调对工具
L3 跨轮改参重跑    "把预算再加10%重新算一遍" → 复用上文对象+新参数
L4 clarify 应答    上轮 clarify，本轮用户补充 → 接着办完（22 §I-2 的老缺口）
```
