**每份 E 报告 §8「下一步」的每一条，要么对上 TRACK-A/B 队列的一个编号，
要么显式写「已结案 / 已停放 / 挂主线 + 理由」。** 核对表在 `TRACK-B §3.6` 与 `TRACK-A §7.6`，
收工时过一遍（已写进 `docs/infra_exp/README.md` §4 第五条纪律）。

**Why**：2026-08-16 Chaoyu 追问「31% 我们是不是只测出来了、没解决」，
一核对发现**列出来的三个成因里只有一个有实验对着**；同一次核对还翻出四个空白：
- 陈旧度节流卡住 rollout —— 列了成因，没人打（→ 新增 B10）
- 生成侧资源配比：生成只占一步的 6.3% 却独占一整张卡 —— **连成因都没列进去**（→ B11）
- 训练侧三次前向占步 **72%** —— 只被 E11/E13 侧面蹭到，没正面打过（→ B12）
- `partial_rollout` 全程一次没触发 —— 只写在 E08 里，队列上没有（→ B4 子项 b）
- 满载 2.3 kW 降频 —— README 自己写着「会污染所有对照」却不在任何队列（→ A7）

★ **归因做完会有一种「已经解决了」的错觉。** 这是 [[project-mechanism-not-wired]] 的近亲：
那个是「机制建好了但没接上」，这个是「问题查清了但没人接手」。
⇒ **防它的办法不是更努力地记得，是让空白在表格里显形**——成因表加一列「谁在打」。

**How to apply**：写完任何归因/画像类结论，立刻做两件事：
① 把成因拆成表，每行加「谁在打」一列；② 空着的格子当场开一个实验编号，
开不出来就写明为什么不做。**别让「我们量出了 X」独立存在。**
